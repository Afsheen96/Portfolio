Overview

Project overview

HighTechZone is my personal website where I share AI tools, practical tech guides and digital-skills content.

I designed and built it myself: a bold dark theme, an animated hero section, clear navigation (AI Tools, Guides, Projects, Services) and a layout that works on phones, tablets and desktops. It is published for free on GitHub Pages.

The challenge

I wanted one home for everything I learn about AI and technology, one that looks modern, loads fast and costs nothing to host.

02

My approach

I designed a bold dark brand with warm gradient accents, wrote clean HTML, CSS and JavaScript without heavy frameworks, and published it on GitHub Pages so it is free and always online.
