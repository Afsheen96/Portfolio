Overview

Project overview

I built this for FOMI's frontend assessment: their Image Generator mockup turned into a real, working Next.js app.

It includes a model picker, reference uploads, a prompt box with keyboard shortcuts, a mocked API that "generates" images and videos, loading placeholders in the right shape, a masonry gallery, a full-size viewer with keyboard navigation, and a guided tutorial that highlights the real controls.

3layouts: phone, tablet, desktop
4-stepguided tutorial
2026built & deployed on Vercel
01

The challenge

A static design mockup does not show how a product behaves. The task was to make every part of it actually work: generating, waiting, browsing and viewing, on every screen size, without a real AI backend.

02

My approach

I rebuilt the interface as reusable React components, added a mocked API so generation feels real, and designed a separate layout for phone, tablet and desktop. On phones the generator becomes a bottom sheet so the gallery always stays in view.

Features

What it does

  • Model picker & references

    Choose a model and add style or character references, just like the original design.

  • Smart prompt box

    Keyboard shortcuts: Ctrl + Enter to generate and / to focus the prompt.

  • Mocked generation API

    Images and videos "generate" with realistic waiting times, so the full flow can be tested.

  • Shape-matched loading states

    Placeholders appear in the exact size and ratio of the coming result.

  • Masonry gallery & viewer

    A tidy gallery with a full-size viewer you can move through with the keyboard.

  • Guided tutorial

    A step-by-step tour that highlights the real controls for first-time users.

  • Three real layouts

    Phone, tablet and desktop each get their own layout, not just a squeezed one.

  • Fast & accessible

    next/image, lazy loading and accessible components throughout.
