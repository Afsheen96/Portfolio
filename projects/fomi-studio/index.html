A

Problem

As part of a frontend hiring assessment, I was given a static design mockup of an AI Image Generator.

A mockup does not show how a product behaves. The task was to make every part of it actually work (generating, waiting, browsing and viewing) on every screen size, without a real AI backend.

B

What I Built

I rebuilt the interface in Next.js as reusable React components styled with CSS Modules: a model picker, reference uploads, a prompt box with keyboard shortcuts and a mocked API that "generates" images and videos with realistic waiting times.

Loading placeholders match the shape of the coming result, the gallery is a masonry grid and a full-size viewer supports keyboard navigation. A guided tutorial highlights the real controls. Phone, tablet and desktop each get their own layout (on phones the generator becomes a bottom sheet), and the app is deployed on Vercel.

Features

What it does

  • Model picker & references

    Choose a model and add style or character references, just like the original design.

  • Smart prompt box

    Keyboard shortcuts: Ctrl + Enter to generate and / to focus the prompt.

  • Mocked generation API

    Images and videos "generate" with realistic waiting times, so the full flow can be tested.

  • Shape-matched loading states

    Placeholders appear in the exact size and ratio of the coming result.

  • Masonry gallery & viewer

    A tidy gallery with a full-size viewer you can move through with the keyboard.

  • Guided tutorial

    A step-by-step tour that highlights the real controls for first-time users.

  • Three real layouts

    Phone, tablet and desktop each get their own layout, not just a squeezed one.

  • Fast & accessible

    next/image, lazy loading and accessible components throughout.

  • Deployed on Vercel

    Live, shareable and updated straight from GitHub.
